# MTG Opening Hand Optimizer

Calculate the probability of getting your ideal opening hand in a 100-card deck (Commander/EDH).

## Live Demo
🔗 **[Try it online](https://mtg-opening-hand-optimizer.streamlit.app)**

## Features
- Dynamic card categories (Lands, Ramp, etc.)
- Configure minimum cards needed in opening hand
- Extra draw requirements (e.g., need 1 more land by turn 3)
- Mulligan support with London mulligan rules
- Auto-optimization to find the best deck configuration
